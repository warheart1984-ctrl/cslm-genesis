# Evidence library

This directory is the independent lookup store. The base LM does not write it.

- `library.json` — established mechanisms, protocol definitions, and hypothesis-status rows
- A row may **support** a claim only when the draft’s asserted value matches the stored value
- A matching subject + predicate with the wrong value is a **contradiction**
- Protocol hypotheses (Phase 6, Faraday–KTHNY membership, universal deception penalty, physical Phase-9 closure) support release only when stated as tests or candidates, not as settled nature

Add new facts here. Do not ask the model to certify them.
